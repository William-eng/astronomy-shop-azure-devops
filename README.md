# Astronomy Shop — Azure DevOps Engineering Project

A hands-on Azure DevOps engineering project deploying the
OpenTelemetry Astronomy Shop microservices application on
Microsoft Azure.

## Objectives

- Provision Azure infrastructure using Terraform.
- Deploy containerized microservices to Azure Kubernetes Service.
- Build CI/CD pipelines using Azure DevOps Agents.
- Implement secure authentication and least-privilege access.
- Integrate observability, monitoring, and alerting.
- Test deployment reliability, rollback, and recovery.
- Document implementation through technical blog articles.

## Technology Stack

- Microsoft Azure
- Azure DevOps Pipelines
- Terraform
- Docker
- Azure Kubernetes Service (AKS)
- Azure Container Registry (ACR)
- Kubernetes
- OpenTelemetry
- Azure Monitor
- PowerShell

## Implementation Phases

1. Environment and Azure DevOps Setup
2. Terraform Remote Backend
3. Azure Networking
4. Azure Container Registry and AKS
5. Astronomy Shop Application Deployment
6. Azure DevOps CI/CD
7. Observability and Security
8. Reliability, Rollback, and Cleanup
